# 宝子 (Baozi) — Full-Stack App

A Flutter mobile app with a Go backend.

## Tech Stack

- **Mobile:** Flutter (Dart)
- **Backend:** Go
- **Platform:** iOS / Android

## Project Structure

```
mobile/     — Flutter app (scaffold)
backend/    — Go HTTP server
```

## Backend

```bash
cd backend
go run cmd/server/main.go
# Server starts on :8080
```
